# 志顺小馆（小仝宝店）· 在线点菜系统

扫码点菜 + 接单后台。**提供两种形态**，按需选用：

| 形态 | 特点 | 文件 |
|---|---|---|
| **① 纯静态版（推荐）** | **无需任何服务器**。顾客页与接单台都是独立网页，订单通过公共消息通道（MQTT）实时传递 | `static/page-order.html`、`static/admin-static.html` |
| ② 服务端版 | 带 Node 后端，订单存在本地文件；适合想自己掌控订单数据的场景 | `server.js` + `index.html` + `admin.html` |

两种形态都**零依赖**（只用 Node 内置模块 / 浏览器原生 API）。

---

## ① 纯静态版（无需服务器，推荐）

### 原理

```
顾客手机  ──打开网页──►  MQTT 公共消息通道  ──►  店内设备（接单台网页）
（任何网络）             （wss 加密，免费）         （任何设备，打开网页即可）
```

- 顾客页与接单台都是**自包含单文件**，可用任意静态托管（甚至本地双击打开）
- 订单通过免费公共 MQTT 通道实时推送，**不需要服务器、不需要数据库、不需要账号**
- 店里设备只需**打开一个网页**就能接单，电脑/手机/平板都行

### 使用步骤

**第 1 步：生成店铺设置（频道码 + 桌贴二维码）**

```bash
node setup-shop.js                 # 自动生成随机频道码
node setup-shop.js ZS7K2M9QP4      # 或指定频道码
```

生成两个文件：
- `static/tables.html` —— **可打印的桌贴页**（一桌一码，每张单独一页）
- `static/channel.txt` —— 频道码与各链接，便于保存

**第 2 步：部署到公网（一次授权即可）**

双击 `一键部署到公网.bat`，按提示粘贴一次 GitHub 令牌。
部署完成后用你的公网地址重新生成桌贴，二维码里就是真实可扫的链接：

```bash
set PUBLIC_BASE=https://你的地址 && node setup-shop.js 你的频道码
```

**第 3 步：接单台**

店员设备打开（或直接双击 `static/admin-static.html`）：

```
https://<你的地址>/admin-static.html?c=你的频道码
```

- 首次打开若没带 `?c=`，会提示填一次频道码，之后自动记住
- **没有公网也能用**：直接双击 `static/admin-static.html` 即可开始接单

### 顾客链接格式

```
https://<你的地址>/page-order.html?t=A14&c=ZS7K2M9QP4
                                   ↑桌号    ↑频道码
```

### 完全离线也能用（无需托管）

两个页面都是自包含文件，**双击就能打开**：店里接单台直接用
`static/admin-static.html`（填一次频道码）即可开始接单，不需要任何服务器或托管。

### 实测验证（真实浏览器 + 真实公共中转）

| 验证项 | 结果 |
|---|---|
| 顾客下单 → 接单台收到（完整订单：桌号/菜品/备注/金额） | ✓ |
| 接单台状态流转（待处理→制作中→已完成） | ✓ |
| `file://` 直接双击打开也能下单 | ✓ 6/6 |
| 浏览器端 MQTT 中转可用性 | ✓ EMQX / HiveMQ / Mosquitto 均 CONNACK rc=0 |

### 用到的公共 MQTT 中转（已实测国内可达）

| 中转 | 地址 | 实测延迟 |
|---|---|---|
| EMQX（首选） | `wss://broker.emqx.io:8084/mqtt` | 498ms |

## ② 服务端版

**顾客端（`/`）**
- 美团风格点菜页：左侧分类 + 右侧菜品 + 底部购物车
- 菜品全部 0 元（免费点），支持热销/推荐/新品角标
- 加减菜带抛物线动画，整卡右侧空白也可点加菜
- 下单备注：常用备注标签多选（口味/忌口/做法/餐具）+ 自定义输入
- 确认订单页：桌号、门店地址、优惠、费用明细
- 下单成功小票：订单号、时间、备注、接单状态

**接单端（`/admin`）**
- 订单列表：桌号、菜品、备注高亮、金额
- 状态流转：待处理 → 制作中 → 已完成
- 5 秒自动刷新，新订单响铃 + 弹窗横幅 + 浏览器桌面通知
- 店员可追加/修改备注
- 口令保护（环境变量 `ADMIN_TOKEN`）

**工具（`/qr` 与 `/tables`）**
- `/qr`：顾客点菜码 + 接单台码，可打印
- `/tables`：**一桌一码**，每张桌单独一页可打印桌贴；顾客扫码后点菜页自动带上该桌桌号
- 内置零依赖二维码生成器（`qr.js`），支持版本 1–16、L/M/Q/H 纠错

**多桌支持**
- 网址参数 `?t=A15` 指定桌号，确认页/订单/后台都显示该桌号
- 购物车**按桌号隔离**，不同桌互不干扰（同一台设备换桌也不会串单）
- 桌号列表由环境变量 `TABLES` 配置（逗号分隔），默认 8 张桌

## 安全说明：为什么需要一个 GitHub 令牌

部署必须把代码放到 GitHub（Render 从仓库构建）。如果由我代劳推送，你需要提供一个
**GitHub 细粒度访问令牌（Fine-grained PAT）**。请了解：

- **权限范围**：只需该仓库的 `Contents: Read and write`（创建新仓库才需要 `Administration`）
- **它能做什么**：只能读写你授权的仓库代码
- **它不能做什么**：无法访问你的邮箱、其他仓库、支付信息；无法以你的身份发帖或改账号设置
- **随时可撤销**：https://github.com/settings/tokens 一键 Delete 即可失效
- **建议**：把有效期设为 7 天，等部署完成后直接删掉令牌

如果你不想提供令牌，也可以自己运行一条命令完成推送（见 `cloud-deploy/上线操作指南.md`）。

## 部署到 Render（免费）

### 为什么选 Render

实测各平台在国内网络的可达性（TCP + HTTPS 完整请求）：

| 平台 | 国内可达 | 传内容 |
|---|---|---|
| **Render** | ✓ 296ms | ✓ |
| **Netlify** | ✓ 398ms | ✓ |
| **GitHub Pages** | ✓ 209ms | ✓ |
| Cloudflare `workers.dev` | ✗ 被墙 | ✗ |
| Cloudflare `pages.dev` | ✗ 522 | ✗ |
| Vercel | ✗ 被墙 | ✗ |

Cloudflare 虽然免注册可部署，但其域名在国内无法访问，因此改用 Render。

### 部署步骤

**方式一：一键脚本（推荐，最简单）**

Windows 下双击 **`一键部署到公网.bat`**，按提示粘贴一次 GitHub 令牌即可。
脚本会自动推送代码，并打开 Render 的一键部署页面，你只需点几下完成授权。

**方式二：手动**

1. 把本仓库推到 GitHub
2. 打开一键部署链接：
   `https://dashboard.render.com/blueprint/new?repo=<你的仓库HTTPS地址>`
3. 完成 GitHub 授权（OAuth）
4. 填写环境变量 `ADMIN_TOKEN`（接单台口令）
5. 点 **Apply**，等待几分钟
6. 得到 `https://<服务名>.onrender.com`

### 服务会休眠？已解决

Render 免费档闲置 15 分钟会休眠，下一个访客要等约 45–60 秒唤醒。
本仓库内置了 `.github/workflows/keep-alive.yml`：**每 10 分钟自动访问一次健康接口**，
服务始终保持唤醒状态 → 顾客点开就是秒开（0 冷启动）。GitHub Actions 对公开仓库免费。

> 若 GitHub 因仓库长期无活动而暂停定时任务，随便改一次该文件即可恢复。

### 环境变量

| 变量 | 说明 | 默认 |
|---|---|---|
| `PORT` | 监听端口（云平台自动注入） | 8080 |
| `ADMIN_TOKEN` | 接单台口令，留空则不校验 | 空 |
| `DATA_DIR` | 订单数据目录 | `data` |
| `TABLES` | 桌号列表，逗号分隔（用于 `/tables` 生成桌贴） | `A14,A15,A16,A17,B01,B02,B03,B04` |

### 注意

Render 免费档的磁盘是**临时**的，服务重启后订单历史会重置（订单数据本身不会丢给顾客，只是你后台看不到旧单）。
若要长期保存订单，建议接一个免费云数据库（Supabase / PostgreSQL），代码里 `readOrders` / `writeOrders` 两处替换即可。

### 用手机当接单屏

- 点菜页在云端，**与手机开关机无关**，顾客随时能点
- 接单台就是个网页，**手机浏览器打开即可**（安卓/iPhone 都行）
- 建议「添加到主屏幕」，并把屏幕自动锁定设长一些
- 页面每 5 秒自动刷新，新订单响铃 + 弹横幅
- 手机锁屏/切后台时页面暂停刷新（所有手机浏览器的限制），解锁回来自动刷新，订单不会丢

## 文件说明

| 文件 | 作用 |
|---|---|
| `server.js` | 后端：静态服务 + 订单接口 + 接单后台 + 二维码页 |

| `admin.html` | 接单台 |

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/menu` | 菜单 |
| POST | `/api/orders` | 顾客下单 |
| GET | `/api/orders` | 取订单（需口令） |
| PATCH | `/api/orders/:id` | 改状态/备注（需口令） |
| DELETE | `/api/orders?scope=done` | 清空已处理（需口令） |
| GET | `/api/health` | 健康检查 |
| GET | `/api/addresses` | 本机局域网地址（二维码页用） |
