# 上线操作指南（只需做一次，约 5 分钟）

目标：拿到一个**永久公网链接**，顾客在任何网络、任何 WiFi、用手机流量都能打开点菜。

---

## 为什么需要你亲自点一下

部署必须有一台 24 小时在线的服务器。**国内能访问的免费平台（Render / Netlify / GitHub Pages）都要求账号**——
而注册账号需要你的邮箱验证，这一步我无法代替（我没有你的邮箱，也不应该用假邮箱代你注册）。

好消息：**你只需要点几下，其余全部由脚本完成**。

---

## 最省事的方式：双击一个文件

在 `D:\KAKAKAKAKA` 目录里，**双击 `一键部署到公网.bat`**。

它会：
1. 提示你粘贴一次 GitHub 令牌（**输入时不显示，不用发给任何人**）
2. 自动把代码推送到 GitHub
3. 自动打开 Render 的一键部署页面

你只需要在打开的网页里：用 GitHub 登录 → 填一个接单口令 → 点 **Apply**。

---

## 那 GitHub 令牌怎么来（约 2 分钟）

1. 注册/登录 https://github.com/signup （邮箱即可，免费）
2. 打开 https://github.com/settings/tokens?type=beta
3. 点 **Generate new token**
   - **Token name**：随便填，例如 `diancai`
   - **Expiration**：建议选 **7 days**（部署完就可以删掉）
   - **Repository access**：选 **All repositories**
   - **Permissions** 展开 → 设两项：
     - `Administration` → **Read and write**（用于创建仓库）
     - `Contents` → **Read and write**（用于写入代码）
4. 点 **Generate token**，复制 `github_pat_...` 开头的字符串

> **安全说明**：这个令牌只能读写你授权的仓库代码。
> 它**无法**访问你的邮箱、支付信息、其他仓库，也**无法**以你的身份发帖或改账号设置。
> 随时可以在同一页面点 **Delete** 让它立即失效。

## 关于「用手机当接单屏」

**完全可以，而且比电脑更省事**：

- 点菜页在云端，**跟手机开关机无关**，顾客随时能点、订单不丢
- 接单台就是一个网页，手机浏览器打开即可（安卓 / iPhone 都行）
- 建议：手机浏览器打开接单台后，**添加到主屏幕**（像 App 一样），并把屏幕自动锁定设长一点
- 页面每 5 秒自动刷新，新订单会**响铃 + 弹横幅**
- 手机锁屏或切到后台时页面暂停刷新（所有手机浏览器的限制），解锁回来自动刷新，**订单一条都不会少**

## 遇到问题怎么办

| 现象 | 处理 |
|---|---|
| 顾客打开要等 30–60 秒 | 服务在休眠。确认 GitHub Actions 里的 keep-alive 在工作流页面是启用状态 |
| 桌贴二维码扫不开 | 打开 `/tables` 重新打印；确认链接是小程序外可访问的普通网址 |
| 忘记接单口令 | 在 Render 后台 Environment 里改 `ADMIN_TOKEN`，保存后自动重启 |
| 想改菜单/店名 | 告诉我，我改完重新推送，链接不变 |
